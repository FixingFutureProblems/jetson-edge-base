# Stage 01 - Flash a Factory-Fresh Jetson

## Objective

Provision a factory-fresh NVIDIA Jetson Orin Nano Developer Kit with the target JetPack release and verify a successful first boot.

---

## Prerequisites

- Ubuntu or macOS host computer
- Internet connection
- USB cable
- NVIDIA SDK Manager installed (or documented alternative)
- Target JetPack version defined

---

## Result

After this stage the Jetson:

- boots successfully
- completes the first-boot wizard
- reaches the GNOME desktop
- has network connectivity
- is ready for further configuration

---

## Validation

Verify:

- Device boots without errors.
- Desktop appears.
- Ethernet works.
- JetPack version matches the expected version.

---

## Troubleshooting

Document every issue encountered during flashing or first boot.

---

## Definition of Done

- [ ] Flash completed
- [ ] First boot successful
- [ ] Network working
- [ ] JetPack version verified
- [ ] Ready for Stage 02
